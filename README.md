# Line Follower — Jetson Nano

Autonomous line-following robot with STOP sign detection, developed in ROS 2 and deployed on a Jetson Nano. The system performs real-time computer vision to estimate lane deviation and heading error, then sends discrete steering commands to an ESP32 microcontroller over HTTP.

---

## Overview

Two ROS 2 nodes run concurrently. The detector node captures frames from a USB camera, segments the white lane using brightness thresholding and Hough line analysis, and independently detects STOP signs via HSV color masking. The controller node subscribes to both topics, computes a weighted control signal, and dispatches drive, steer, brake, and blink commands to the vehicle. All telemetry is logged to CSV and analyzed post-run with a dedicated plotting script.

```

                    │ ROS 2 topics
┌───────────────────▼─────────────────────┐
│              controller_node             │
│                                         │
```

## Control Logic

### Lane Detection (`lane_stop_detector_node.py`)

Detection is confined to the lower half of the frame (ROI starting at 50% of frame height) to exclude background clutter.

- **Lateral offset**: white columns are segmented by grayscale threshold (`WHITE_V_MIN = 155`). Left and right centroids are averaged to find lane center deviation from the image midpoint. A dead zone of ±25 px suppresses noise when the robot is well-aligned.
- **Heading angle**: `HoughLinesP` extracts lane line segments. The median angle of valid lines (|angle| > 5°) is used as the heading estimate. Dead zone: ±8°.

### STOP Sign Detection (`_detect_red_stop`)

- HSV dual-range masking covers both low-hue red ([0–10]) and high-hue red ([170–180]).
- Morphological open and close operations remove noise and fill gaps.
- Contour filtering by area (> 600 px²), aspect ratio (0.55–1.8), and bounding box area relative to frame (0.2%–20%) rejects floor reflections and unrelated objects.

### Controller (`controller_node.py`)

The control signal combines both visual errors linearly:

```
control_v = offset_px + heading_deg * HEADING_K
```

This scalar is then discretized into one of five steering commands:

| control_v range        | Command | Direction         |
|------------------------|---------|-------------------|
| > OFFSET_HARD (90)     | `a`     | Hard left         |
| > OFFSET_SOFT (55)     | `al`    | Soft left         |
| < -OFFSET_HARD (-90)   | `d`     | Hard right        |
| < -OFFSET_SOFT (-55)   | `dl`    | Soft right        |
| otherwise              | `c`     | Straight          |

On STOP detection, the vehicle brakes for 5 seconds. A latch flag prevents retriggering until the sign is no longer visible and the stop cycle completes.

If no lane data arrives for more than 1 second (topic timeout), the controller applies the brake as a safety fallback.

## Running the System

Launch each node in a separate terminal with the ROS 2 environment sourced:

```bash
# Terminal 1 — Vision node
python3 lane_stop_detector_node.py

# Terminal 2 — Controller node
python3 controller_node.py
```

When interrupted with `Ctrl+C`, `controller_node` automatically saves a timestamped CSV to `logs/` and sends a brake command to the ESP32.

---

## Log Analysis

```bash
python3 plot_controller_logs.py
# or specify a log file explicitly:
python3 plot_controller_logs.py logs/controller_log_<timestamp>.csv
```

Outputs 15 figures and a quantitative summary text file to `plots/`, covering lateral and angular error convergence, control effort, servo discretization, stability (rolling standard deviation), perturbation sensitivity (signal derivative), and STOP event timeline.

## Configurable Parameters

| Parameter       | File       | Default              | Description                                      |
|-----------------|------------|----------------------|--------------------------------------------------|
| `ESP32_IP`      | controller | `http://192.168.10.1`| ESP32 base URL                                   |
| `OFFSET_SOFT`   | controller | `55`                 | Threshold for soft steering                      |
| `OFFSET_HARD`   | controller | `90`                 | Threshold for hard steering                      |
| `HEADING_K`     | controller | `1.5`                | Heading weight in the control signal             |
| `STOP_SECONDS`  | controller | `5.0`                | Braking duration after STOP detection (seconds)  |
| `WHITE_V_MIN`   | detector   | `155`                | Minimum brightness value for white lane pixels   |
| `LANE_ROI_START`| detector   | `0.50`               | Vertical ROI start as fraction of frame height   |
| `TIMER_HZ`      | detector   | `10.0`               | Vision loop frequency (Hz)                       |
